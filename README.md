# Hide bot
*Телеграм бот для мгновенного сохранения различного рода контента в телеграм чате*

[Ссылка](https://t.me/hidexv4bot) на бота
> @hidexv4bot

Этот бот хранит любые ваши данные в секретном
хранилище, доступ к которому есть только у вас. 
Все присылаемые сообщения распределяются по так 
называемым "комнатам".

Существуют публичные комнаты и приватные, 
для приватных нужен ключ доступа 
(более того, без этого ключа даже нельзя понять, существует 
ли она вообще), публичные это по сути просто папки 
для файлов

## Функционал
Бот хранит несколько видов данных:
1. Текст, картинки
2. Аудио сообщения
3. Видео

Из главного меню можно зайти в любую комнату с помощью кнопки "Список комнат" или просто написав боту ее название

Находясь в комнате можно просматривать ее содержимое и добавлять новое, просто присылая его боту (или пересылая из других чатов)

Если в комнате переслать сообщение обратно боту, добавив точку ("."), оно будет удалено

*Не забывайте возвращаться обратно в главное меню для удобства*

Если вы перешлете сообщение (только одно) боту (который находится в главном меню), 
он предложит вам добавить присланный вами контент в нужную комнату

Из меню, по кнопке "Настройки комнат" вы сможете:
1. Удалить ненужные комнаты (*безвозвратно*, со всем содержимым)
2. Переименовать или сменить ключ у приватной комнаты
3. Поменять видимость: сделать публичную приватной или наоборот

Если в чате появились лишние, мешающие сообщения (которые по каким-либо причинам не исчезают), можно их удалить или вообще очистить историю с ботом

## Релиз

Команда
```shell

```

## Разработка
В файле `.env` содержатся необходимые переменные для локально запуска. 

Они рассчитаны на то, что поднят postgres сервер локально с базой данных postgres.
Этот файл содержится в `.gitignore` так как в продакшине используются другие переменные окружени
Они установлены непосредственно на `heroku.com`

Вот необходимые список
```shell
TEST=True # Можно не указывать
ENV_VALID=True # Обязательно именно так, нужно, чтобы удостовериться в всех переменных окружения. Выставляется в последнюю очередь
BOT_API_KEY= # API_KEY бота в тг. Имеет формат 324324:ijsdfojasdfiodsfj См. BotFather
PG_URL=postgresql://postgres:postgres@localhost:5432/postgres # Url для обращения к базе данных. Тут приведен пример с локальной
```
