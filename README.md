# Hide bot
*Телеграм бот для мгновенного сохранения различного рода контента в телеграм чате*

[Ссылка](https://t.me/hidexv4bot) на бота
> @hidexv4bot

Этот бот хранит любые ваши данные в секретном
хранилище, доступ к которому есть только у вас. 
Все присылаемые сообщения распределяются по так 
называемым "комнатам".

Существуют публичные комнаты и приватные, 
для приватных нужен ключ доступа 
(более того, без этого ключа даже нельзя понять, существует 
ли она вообще), публичные это по сути просто папки 
для файлов
