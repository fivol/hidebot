# YourCloudBot

[Ссылка](https://t.me/your_cloudbot) на бота

> @your\_cloudbot

Этот бот хранит любые ваши данные в секретном хранилище, доступ к которому есть только у вас. Все присылаемые сообщения распределяются по так называемым "комнатам".

Существуют публичные комнаты и приватные, для приватных нужен ключ доступа \(более того, без этого ключа даже нельзя понять, существует ли она вообще\), публичные это по сути просто папки для файлов

## Функционал

Бот хранит несколько видов данных: 1. Текст, картинки 2. Аудио сообщения 3. Видео

Из главного меню можно зайти в любую комнату с помощью кнопки "Список комнат" или просто написав боту ее название

Находясь в комнате можно просматривать ее содержимое и добавлять новое, просто присылая его боту \(или пересылая из других чатов\)

Если в комнате переслать сообщение обратно боту, добавив точку \("."\), оно будет удалено

_Не забывайте возвращаться обратно в главное меню для удобства_

Если вы перешлете сообщение \(только одно\) боту \(который находится в главном меню\), он предложит вам добавить присланный вами контент в нужную комнату

Из меню, по кнопке "Настройки комнат" вы сможете: 1. Удалить ненужные комнаты \(_безвозвратно_, со всем содержимым\) 2. Переименовать или сменить ключ у приватной комнаты 3. Поменять видимость: сделать публичную приватной или наоборот

Если в чате появились лишние, мешающие сообщения \(которые по каким-либо причинам не исчезают\), можно их удалить или вообще очистить историю с ботом

## Способы использования

1. Сохранять важные сообщения из чатов по публичным комнатам
2. Группировать единичные фотографии из галереи как в "сохраненки", только в комнату с нужным, интуитивным названием
3. Завести основную приватную комнату \(хорошо запомнить ее ключ\) и скидывать туда любую секретную информацию, которую вы хотите утаить от вашего окружения. Вот несколько примеров:
   * Фотографии с вечеринки, на которой вас не должно было быть
   * Компроматы на других
   * Видео, присланные из других чатов, от которых вы постоянно отписываетесь ;\)
   * Личные аудиосообщения, которые "опасно" хранить с чате "Saved messages" \(по русски Сохраненные сообщения\)
4. Вести аудиодневник в одной из приватных комнат
